check that the rule still matches after a release bump.

## 2026-09-28T07:43-07:00 — decision: fix the `elf_test` flake in `rules/driver_elf_test.sh` (M10's)

to pass and the fix is 3 lines; kept in its own WIP commit so the orchestrator can drop
