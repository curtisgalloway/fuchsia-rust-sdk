## 2026-09-28T06:27-07:00 — surprise: who ships `libdriver_runtime.so`
Across 174 driver binaries: 159 need `libdriver_runtime.so`, only 8 packages' binaries
ship it (the three pure-Rust driver packages, their `compat.so` siblings, iwlwifi), so
the driver host provides it. Every other needed library but `libc.so`/`libzircon.so` is
always shipped in the package (`libasync-default.so`: 29 need, 29 ship). rules_fuchsia's
`fuchsia_cc_driver` deliberately packages `libdriver_runtime.so` too.
