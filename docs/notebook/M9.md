## 2026-09-28T04:09-07:00 — attempt: visibility experiment confirms the reviewer's explanation
Scratch edits in the worktree, reverted with `git checkout` (`git status` then showed only
this chapter; `regen.py --check` clean). A: `fdf_core` (declared inside the symbolic macro
`rustc_library`) set `//visibility:private` and added to `library_deps` in

## 2026-09-28T04:09-07:00 — correction of 2026-09-28T03:51-07:00
"Cause not established; the candidate is a `select()` branch" is wrong (04:09). Every
crate an overlay or upstream file declares with `rustc_library` is declared inside that
symbolic macro, defined in `//rules`, so it is visible to edges written in `//rules`
code; the `fidl_next` alias (M8b) is a top-level `alias`, which is why it needs
`//rules:__pkg__`. Decision: `fidl_driver`'s added `//rules:__pkg__` is redundant, so it
is removed, and the overlay's visibility is GN's exactly.
