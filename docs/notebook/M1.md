## 2026-09-27T18:11-07:00 — decision: lock schema details
Every field is `{"value": …, "source": [ … ]}`; `source` is always a list (several
artifacts must agree for the revisions). Git sources are written `<repo> <rev>:<path>`
(a real `git cat-file` revspec, not a gitiles URL); CIPD sources use the package's
`https://chrome-infra-packages.appspot.com/p/<pkg>/+/<tag>` name. CIPD fields also carry
`package`, so M2 need not parse a URL. `rules_fuchsia` is resolved by
`git_revision:<integration_revision>` (the orchestrator's decision); when
`version:<V>` also resolves it must name the same instance, else the run fails.
